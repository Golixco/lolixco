# Media provenance

- `public/brand/*.png`: supplied user brand reference files copied without pixel modification. CSS trims only surrounding presentation margins. Replace through BrandLogo / BrandIcon with production SVGs when supplied.
- `public/media/art-*.svg`: original programmatic geometric city illustrations created for this project by scripts/create-art.mjs. No screenshot crops or third-party characters.
- `public/media/motion-study.webm`: original silent browser-recorded test animation of art-0.svg, approximately 12 seconds at 960x540. No commercial audio or third-party footage. All demo cards intentionally share this test source.
- Inter and Rajdhani: self-hosted Fontsource packages, SIL Open Font License. License files remain in their respective installed packages.
- Lucide: ISC-licensed icon library.

Reference filenames containing guest/member are design references only. No real platform users, statistics or verification are represented. The supplied brand assets' final publication rights should remain with the project's owner; no publication was performed.
